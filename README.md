# Titelgeneratorn

Ett interaktivt verktyg som hjälper jobbsökande, konsulter och generalister inom marknad, kommunikation, design och media att hitta rätt yrkestitlar utifrån sina främsta färdigheter.

## Funktioner
* **Färdighetsmatchning:** Välj upp till 5 kärnkompetenser och filtrera på operativ eller strategisk nivå.
* **Hybridrubrik-studio:** Kombinera två roller till en skräddarsydd hybridtitel i olika format (`/`, `·`, `//`) för LinkedIn och CV.
* **Pitch-generator:** Genererar automatiskt en sammanfattande introduktionstext baserad på valda roller och färdigheter.
* **Lätt & fristående:** Byggd i ren HTML, CSS och vanilla JavaScript utan externa beroenden, med stöd för mörkt och ljust läge.

## Underlag & Krediter
Rollbeskrivningar och branschkategorier är strukturerade utifrån *Titelguiden* från Knack Rekrytering.
